# Legacy examples

These scripts reference the removed `Array64Config.snap_to_ant64` /
`ant64_to_snap` reorder maps (replaced by `antenna_ids` in v2.0 of the
HDF5 schema) and the legacy 64-slot allocation (now 72 = 6 SNAPs × 12
ADCs). They are kept here for historical reference and **will not run
against the current API**. For current usage patterns see the top-level
`examples/` directory or the README.
